# Chuwi Facial Emotion Behavior Mapping

Pipeline:

Camera -> FacialEmotionModel -> FacialRuntime -> Emotion Manager -> Robot Behavior

Mappings:

| Emotion | Behavior |
|---|---|
| CALM | Normal interaction |
| HAPPY | Joyful and engaging |
| SAD | Empathetic support |
| FEAR | Reassuring response |
| ANGER | Calm de-escalation |
| SURPRISE | Interactive response |
| DISGUST | Gentle support |

The emotional state influences voice style, facial expression and response strategy.
