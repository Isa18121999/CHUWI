# Chuwi Hardware-Affective Architecture

## Physical definition

Chuwi is an affective plush robot. It does not include:

- screen display
- facial animation
- servo motors
- mechanical movements

Emotional expression is generated through perception, dialogue and voice interaction.

## Sensors

- Camera: facial analysis
- Microphone: voice interaction
- Proximity sensor: user presence detection

## Emotional pipeline

Camera + Microphone + Proximity

```
Multimodal Perception
        |
        v
Emotion Fusion Engine
        |
        v
Chuwi Emotional Manager
        |
        +----------------+
        |                |
        v                v
 Personality      Conversation
        |
        v
 Voice / TTS Output
```

## Expression strategy

Emotion is expressed through:

- voice tone
- speaking speed
- pauses
- empathetic responses
- conversation style
- memory adaptation

## Example

SAD:

- calm voice
- slower speech
- supportive response

HAPPY:

- energetic voice
- playful interaction

FEAR:

- reassuring voice
- calming response
