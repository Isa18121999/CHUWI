# Child Faces Age Adaptation Dataset

Dataset de rostros infantiles utilizado para adaptación y validación del módulo facial de Chuwi.

## Organización

- 5-9 años
- 9-12 años
- 12-16 años

## Uso en Chuwi

Este dataset no se usa como dataset principal de emociones porque no contiene etiquetas emocionales originales.

Uso:
- adaptación a rostros infantiles
- validación por grupos de edad
- pruebas del detector facial

El entrenamiento emocional principal utiliza datasets con etiquetas de emoción.
